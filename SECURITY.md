# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Context-Engineer seriously.

If you discover a security vulnerability (such as unintended remote code execution, token leakage, prompt injection vectors, or unintended network downloads), please report it responsibly:

- Do **NOT** create a public GitHub issue.
- Please email the maintainers or report via GitHub Security Advisories.
- Include a minimal reproduction script and details on affected configurations.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
